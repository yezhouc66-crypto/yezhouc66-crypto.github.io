🚀 《倒立摆挑战》
欢迎来到经典控制理论与物理模拟挑战！倒立摆（Inverted Pendulum）是航空航天火箭发射姿态调整、双足机器人行走和赛格威平衡车的基础核心模型。
🎮 手动挑战模式: 方向键 / A-D / 触屏推小车，防止摆杆倾倒超过 45° 并不撞墙，坚持越久扰动越强！
🤖 PID 演示模式: 探索比例、积分、微分算法如何自动回正倒立摆，并用“戳一下”测试系统抗扰刚度。
📖 物理方程与控制理论

1. 动力学物理方程 (Lagrange 方程):
考虑小车质量 M，摆杆质量 m，转动惯量 J，杆长中心距 l，摩擦阻尼 μ：
• (M + m)ẍ + ml cos(θ)θ̈ - ml sin(θ)θ̇² = F - b·ẋ
• ml cos(θ)ẍ + Jθ̈ - mgl sin(θ) = -μ·θ̇
本系统采用 Runge-Kutta 4阶 (RK4) 显式积分法，数值极为平滑精准。


2. 手动模式规则:
• 角度超过 ±45° 或小车撞击轨道端点即失败。
• 随时间推移，环境随机阵风扰动将逐步加剧。


3. PID 调参秘籍:
• Kp (比例): 反应灵敏度。过小倒立不稳，过大会引起高频剧烈抖动。
• Kd (微分): 阻尼项。抑制震荡超调，提供稳定性。
• Ki (积分): 消除常值微小倾角稳态误差。
• 位置项 (Kp_x, Kd_x): 让小车在稳摆的同时回到轨道中心。
